# reset-cadder-architecture

Rebaseline Cadder around daemon-owned runtime state, a Caddy-compatible shim, operator clients, explicit platform boundaries, and OpenSpec-based planning.

This active change now tracks the approved [Node migration](node-migration.md).
The original Rust reset is archived separately. The current released Rust 1.0.5
workspace remains the operational baseline; the historical 0.8 behavior evidence
does not replace it or reduce the approved 2.0 scope.
