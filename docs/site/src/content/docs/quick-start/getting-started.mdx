## What You Need

- A real Caddy binary installed somewhere on your machine.
- A Cadder runtime installer or portable runtime archive for your OS from [GitHub Releases](https://github.com/MrMaxie/cadder/releases/latest).
- A project with a `Caddyfile`.

See [Releases and downloads](../../reference/releases/) if you are deciding between the native runtime installer and portable runtime archive.

## Configure Real Caddy

Edit the provided `cadder.toml` beside the Cadder executables. Set `[caddy].real_command` to the real Caddy command on `PATH`, or `[caddy].real_path` to its absolute path. See [cadder.toml](../../user-guide/cadder-toml/) for syntax.

## Run A Project

```sh
cadder setup shim
cadderd
cadder daemon status
caddy run
```

`cadder setup shim` creates the optional `caddy` alias after checking for an existing command. The shim attaches to `cadderd`, registers the project Caddyfile, and keeps that registration alive while the command is running. If the daemon is unavailable, the shim names the `cadder daemon start` recovery action and exits without starting unmanaged Caddy.

Inspect Cadder with CLI or TUI:

```sh
cadder entrypoint list --output json
cadder logs show --limit 20 domain app.localhost --registration shim-1
cadder tui
```

`cadder tui` starts the interactive operator surface.
