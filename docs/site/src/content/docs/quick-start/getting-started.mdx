## Install

Download the `cadder` archive and matching SHA-256 file for your platform. Extract its `cadder`, `cadderd`, and `caddy` executables into one user-owned directory and add it to PATH.

Copy `cadder.toml.example` to `cadder.toml` beside the executables and configure real Caddy:

```toml
[caddy]
real_path = "C:/Tools/caddy/caddy.exe"
```

On Linux or macOS, use an absolute native path such as `/usr/local/bin/caddy-real`. You may configure `real_command` instead of `real_path`, but never both.

## Run projects

From each project containing a Caddyfile, run:

```sh
caddy run
```

The shim starts or attaches to `cadderd`, registers the project's routes, and keeps the registration alive until the command exits. Start more projects the same way; the daemon composes their non-conflicting domains behind one Caddy runtime.

Open the operator:

```sh
cadder tui
```

Use Status to start, stop, or restart the daemon, Domains to inspect and toggle routes, and Logs for bounded redacted runtime output.
