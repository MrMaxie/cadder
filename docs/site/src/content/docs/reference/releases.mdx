---
title: Releases and upgrades
description: Verify, install, and replace Cadder release archives.
---

Cadder publishes one versioned `cadder` archive for Windows x64, Linux x64, Intel macOS, and Apple Silicon macOS. Each platform archive has a neighboring SHA-256 checksum.

Every archive contains the version-matched `cadder`, `cadderd`, and `caddy` executables together with the README, changelog, Apache-2.0 license, and sample configuration. Extract the archive into one directory.

Verify the archive before extraction with the platform's SHA-256 tool. Do not combine versions: the exact protocol handshake deliberately rejects mixed releases.

For a manual upgrade:

1. Open `cadder tui`, press `x`, and confirm Stop.
2. Replace all three executables from the same release.
3. Keep or update `cadder.toml`.
4. Run `caddy run` in a project or select Start in the TUI.

The release workflow and checksums are generated by cargo-dist from the repository's pinned configuration.
