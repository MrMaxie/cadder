---
title: Operator TUI
description: Inspect and control Cadder from the keyboard.
---

Launch the operator with:

```sh
cadder tui
```

The 1.0 operator intentionally has one interactive surface. It does not expose a parallel scripting CLI.

## Views

- Status shows daemon, Caddy, and storage health and provides Start, Stop, and Restart.
- Domains groups every registered domain under its project entrypoint and supports activation toggles.
- Logs shows a bounded list of redacted events for the selected runtime, entrypoint, or domain.

Tab, Left, and Right switch views. Up and Down move through lists of any length. Enter opens details. Space performs the current action. Stop and Restart require confirmation. Esc closes details or confirmation, and Ctrl+C exits while restoring the terminal.

Loopback upstreams show only the useful port. Project paths emphasize the repository-relative suffix, or the final folder when the path is not inside a Git repository.
