---
title: Operator TUI
description: Inspect and control Cadder from the keyboard.
---

Launch the operator with:

```sh
cadder tui
```

The 1.0 operator intentionally has one interactive surface. It does not expose a parallel scripting CLI.

## Workspace

The main table groups every registered domain under its project. A filled circle is enabled and an empty circle is disabled. The header keeps global Caddy health visible without repeating diagnostic state.

Up and Down move through lists of any length. Space toggles the selection. Press `l` to open or close bounded redacted logs for that project or domain. Press `x` to stop or `R` to restart; both actions require inline confirmation. When Cadder is offline, Enter starts it. Press `q` or Ctrl+C to exit while restoring the terminal.

Loopback upstreams show only the useful port. Project paths emphasize the repository-relative suffix, or the final folder when the path is not inside a Git repository.
