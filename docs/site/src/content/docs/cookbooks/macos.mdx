---
title: macOS
description: Run the portable Cadder release on Intel or Apple Silicon macOS.
---

Download the `cadder` archive for your architecture. Extract `cadder`, `cadderd`, and the `caddy` shim into one user-owned directory, mark them executable, and add the directory to PATH.

```toml
[caddy]
real_path = "/usr/local/bin/caddy-real"
```

Run `caddy run` from a project and `cadder tui` from any terminal. Cadder uses owner-only local IPC and does not require administrator privileges for unprivileged listeners.
