---
title: Windows
description: Run the portable Cadder release on Windows.
---

Extract `cadder.exe`, `cadderd.exe`, and the `caddy.exe` shim into one user-owned directory. Add that directory to your user PATH and configure an absolute native executable:

```toml
[caddy]
real_path = "C:/Tools/caddy/caddy-real.exe"
```

Run `caddy run` from a project and `cadder tui` from any terminal. Cadder uses an owner-only named pipe and an owner-protected SQLite database. Administrator rights are not required for normal unprivileged listeners.
