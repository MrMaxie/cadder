## Keep the Caddyfile. Let Cadder run the shared runtime.

Each repository keeps its own Caddyfile. The Cadder `caddy` shim registers it with `cadderd`, which combines active routes and applies them through one real Caddy process.

```txt
shop.localhost {
  reverse_proxy localhost:3000
}
```

Run the same command inside that project:

```sh frame="none"
caddy run
```

The route appears in `cadder tui`, where you can inspect its owner, target, and activation state.
