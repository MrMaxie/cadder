# Security policy

## Supported versions

Security fixes are provided for the current stable release line.

| Version | Supported |
| --- | --- |
| 1.0.x | Yes |
| < 1.0 | No |

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability.

Use GitHub private vulnerability reporting for this repository. If that is not available, contact the repository owner through GitHub.

Include enough information to reproduce and assess the issue privately:

- affected Cadder version;
- affected platform;
- affected component, if known;
- steps to reproduce;
- expected security impact;
- logs or proof-of-concept material that are safe to share privately.

Do not include secrets, credentials, or private infrastructure details unless they are required to demonstrate the issue. Redact anything that is not needed for reproduction.

Security reports are handled privately until a fix or mitigation is available.
